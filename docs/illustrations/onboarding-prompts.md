# 扩列图解：插画资产与生成提示词

采用 imagegen 内置工具生成，使用第一张扫码图作为后续图片的角色与风格参考；未使用 CLI/API fallback。资产导出为 1024px 宽的 WebP（quality 90），离线打包进应用，无运行时网络请求。应用中的文字与无障碍描述由 Compose 绘制，不烘焙进图片。

## 风格与输出

MBTI 测试式的轻松简笔插画：无五官的小熊／兔子头套人物、几何服装、莓红轮廓、粉色／鼠尾草绿／暖白背景。图形用于说明动作，不包含可扫描的真实二维码或用户信息。

- `app/src/main/res/drawable-nodpi/onboarding_qr.webp`：出示二维码、扫码、确认与互换卡片。
- `app/src/main/res/drawable-nodpi/onboarding_nearby.webp`：发现附近的人、选择对方并发起申请、接收方确认。
- `app/src/main/res/drawable-nodpi/onboarding_nfc.webp`：手机 NFC 区域贴近、识别与互换卡片。
